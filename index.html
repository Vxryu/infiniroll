Badge rarity

Each badge has a rarity based on how likely you are to roll it. Rarer badges are worth more EP. Badge rarity is determined by probability:

Numbers range from 0 to 1,000,000. Every number has the same odds, except 0 (1 in 25,000,000) and 1,000,000 (1 in 100,000,000). A badge is worth about 100 ÷ its probability in EP.
